# FrontierPlan contributor guide

Preserve Director-only research/design/dialogue before implementation. Main is the
execution coordinator, not the final acceptance authority. Both SKILLs are explicit
only. Keep effort values lowercase, profiles role-specific and common contracts
single-source. Do not add an unavailable Fable route, implicit invocation, daemon,
auto config mutation or hidden backend fallback. Native tool calls stay native.

Run validation, unit tests and standalone packaging after changes. Keep real-host
smoke evidence distinct from simulated tests. Maintain MIT notices for adapted code.
